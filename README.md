# Luffor

A complete, dependency-free editorial portfolio in deep navy and warm ivory.

## Run locally

```sh
npm run dev
```

Open `http://localhost:4173`. Node 18 or newer is required. No installation is needed.
`npm run build` validates the ready-to-publish `dist/` directory. `npm run check` runs the same source, asset, and case-study checks.

## Personalise

- `dist/site-data.js`: studio name, original logo asset path, location, specialty, availability, genuine email/social links, and all four project titles, descriptions, images, and case-study content. Set these once; project information updates on both the homepage and its study.
- `dist/index.html`: headline, introduction, biography, capability entries, and other editorial copy. Update the page description, social metadata, and canonical URL if hosting elsewhere.
- `dist/styles.css`: palette, type scale, spacing, responsive layouts, and motion preferences.
- `dist/assets/`: locally served artwork, project SVGs, fonts, and font licenses.

The supplied brief referred to a sail logo, but the attachment contained only text. The site therefore uses a temporary typographic wordmark. Add the original logo to `dist/assets/`, then set `brand.logo` in `site-data.js`. It will be displayed in its original proportions.

All four projects are clearly identified concept placeholders. Biography, dates, role, outcomes, location, specialty, availability, email, and social destinations intentionally remain replaceable. No clients, awards, or performance claims are invented. Missing email and social links open a clear placeholder notice rather than navigating to a nonexistent account. Adding genuine details activates the normal email and external profile links.

## Images

The original ocean engraving was made with the built-in image generation tool and saved into the site as `dist/assets/ocean-engraving.webp` (2172 × 724, about 373 KB). Its production prompt is in `ARTWORK.md`.

Project artwork is editable SVG generated by `scripts/make-project-assets.mjs`. Regenerate it with `node scripts/make-project-assets.mjs`. Replace the four primary files and their supporting detail files with real assets when available. Keep their aspect ratios, or update the explicit dimensions in `index.html`.

## Interaction and accessibility

The site has a mobile navigation menu, four shareable hash-based case-study views, next-study links, contact/profile notices, scroll reveals, visible focus, native modal focus containment, Escape dismissal, and restored focus after dismissal. Reduced-motion preferences disable animation. All editorial content is present independently of animation.

Fonts and imagery are local. There are no analytics, forms, animation libraries, or third-party requests at runtime.

## Hosting

`dist/` is the complete static website. `.openai/hosting.json` retains the private Sites project identity. The local preview server is development-only and is not part of the published website.
